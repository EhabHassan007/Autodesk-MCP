# Paper-space annotation, viewport and office blocks

For `paper`, pass `layout` (with `apply`). **Recommended: `create_viewport` true.** The tool then makes the viewport itself on layer `G-ANNO-VPRT` (created not plotted, colour 8; an existing layer is used as it is): at `view.paper_centre`, which defaults to the centre of the layout's sheet when applying (approximate by a few millimetres because of printer margins), sized to the parts plus 10 mm each side or `view.viewport_size [w, h]` in paper mm, with its view centred on the detail's model centre, set to 1:scale and display-locked. It is made last, in its own Undo group (three groups in all: geometry, annotation, viewport). The view is centred by switching into the viewport and zooming, after a regen (live-proven on AutoCAD 2024; without the regen AutoCAD answers "There is no active modelspace viewport"); if that fails, through the viewport's Target, the method of the counter sheets. The real view centre is then read back with one read-only AutoLISP query and corrected through Target if it is off; `viewport_result` says the `method`, `view_centre` and whether it was `view_centre_read_back`. If the viewport cannot be made, it is removed and the result (not an error) carries `viewport_error` and `viewport_next_step`, with the geometry and annotation results intact. Undo is typed by the user in AutoCAD; an AI's `U` sent as a command does not run. Without `create_viewport`, pass `view.paper_centre` = the Center of an existing 1:scale viewport whose view is centred on the result's `model_centre`; the tool warns (`viewport_warning`) if the layout has no viewport at that scale but cannot check the centre. Optional `view.model_centre`; the default is the centre of the parts. **Office blocks in paper mode.** Notes are leaders: the office `Multiple Leader Lab` block (`leader_block` names another) with its `LABEL` text wrapped to `note_width` paper mm (default 45) and drawn to the target by its dynamic Distance1, Distance2 and Angle1; if the block is not in the drawing, a native multileader with an arrowhead is used, never a bare line. Levels use the `level indicator` block (`level_block`, `level_block_scale`): the elevation goes to `LEVEL` and the description to `Area` (the tool resolves the roles `@elevation` and `@description` from the tags the block has). The view title uses `DWG-VIEWTITLE` (`title_block`) with `sheet {project, sheet_no, view_no}` in TOP-TITLE, SHEET-NO and KY. A level in `custom_section` takes `label` (one line) or `elevation` with an optional `description`. A block missing from the drawing is reported in `warnings` and the plain annotation is used. `layer_scheme` is `auto` (the office counter-sheet layers when the drawing already has them, else the generator's own), `generic` or `ao`. Details of the office standard: `references/office-sheet-standard.md`.

Both plans are checked against the drawing before anything is drawn. If the annotation fails after the geometry was drawn, the annotation is rolled back and the message says the geometry stays; undo once to remove it.
