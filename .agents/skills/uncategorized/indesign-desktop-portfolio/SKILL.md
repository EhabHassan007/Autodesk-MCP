Read [the knowledge handoff](references/handbook.md) for setup, native scripting lessons, visual treatments, and validation. Use its paste-ready prompt when helping a new user get started.

Check the receiving session's available tools before claiming access to InDesign. This skill provides workflow knowledge; it does not install a connector or computer-control runtime. Use the environment's supported desktop or document tools and their instructions. If desktop control is unavailable, prepare scoped JSX for the user to run through the native Scripts panel, and clearly distinguish preparation from execution.

Inspect the actual current document, scope, latest CV, design reference, fonts, and links. Save a separate working INDD before redesigning an original. Use native editable text, styles, frames, and pages; preserve source artwork and full stories. Resolve collection objects before inserting pages or layers, guard scripts by document identity, and group coherent changes for undo.

Treat the handbook's colors, typography, and cover/introduction structure as optional examples. The current user's reference and preferences take precedence. Prior document paths, page counts, IDs, and biography do not transfer.

Recompose, check overset and asset/font status, inspect the changed pages in native InDesign, fix visible defects, and save. Return the actual native file path and checks performed. Export PDF only on request. Leave the result visible for review when desktop access is available.
